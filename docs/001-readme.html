Resum: el kit d'oferta (kit01 + kit02) produeix el model del tenant (automatismes → skills de l'Hermes, MCPs, JSON n8n, ordre de desplegament). El Build Pack descriu com es desplega un tenant (Control Plane/Optimus, signer, Action Gateway, tenant aïllat amb business-os + n8n + Hermes del client). El pont que els uneix (onboarding del tenant alimentat pel model del kit) és el que falta construir.

Notes de vigència

  • Les xifres comercials dels autors NO són benchmarks de SPAI.
  • Abans d'usar-ne parts com a procediment, contrastar amb les skills vigents i l'estat real de l'entorn; els documents ho demanen explícitament (no "incorporar" per haver-los llegit).
  • Aquesta col·lecció no autoritza cap desplegament ni acció a producció.
