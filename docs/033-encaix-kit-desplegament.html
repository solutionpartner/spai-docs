Flux de deploy governat

CI construeix → signer signa (Ed25519) → Control Plane registra
→ aprovador humà autoritza → deploy worker del tenant fa pull i valida
→ handler local aplica → health + stat "applied" verificats

Mutacions via propose_action → aprovació → execute_approved_action. Rollback: POST /deployments/{id}/rollback. Un rollback de codi NO desfà un efecte extern.
